# Sticker

A 3D object from assets/Stickers, the colour of the app.

**Provide:** `src` (a sticker url), `size` (px, default 96), `tilt` (degrees), `bob` to make it the one floating sticker on the screen (stickers are still by default), `alt` if it carries meaning. Without `src` a neutral placeholder shows.

- Objects (no text) go in the app; the sticker pack (slogans, labels and gathr's dot sticker and stamp) goes in social, print and collages.
- One per card in the app, two or three in a collage. Always on a dark ground.
- **One bob per screen.** Pass `bob` to a single hero sticker; the selected MoodTile does this for you. Stops under reduced motion.
