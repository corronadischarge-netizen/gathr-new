# Wordmark

The gathr logo: **gathr.** in Plus Jakarta Sans Bold (option J76), converted to vector outlines, with one true circle after the r. This is the only dot.

**Construction:**
- **Letters:** Plus Jakarta Sans 700, lowercase, tracked −6% (−60 units at 1000 upm).
- **Dot:** diameter = 1.25 × the stem width (164 units on a 131-unit stem). It sits on the baseline with the round letters' overshoot. The gap after the r is 0.15 × the stem width (20 units), tight to match the tracking.
- **Clear space:** the x-height (544 units) on every side. Minimum size is 16px tall on screen and 5 mm in print.

**Provide:** `size` (height in px) and `tone`:
- `auto`: ink letters, with a yellow dot in night and a violet dot in day.
- `light`: white letters and a yellow dot, for dark canvases and photos.
- `dark`: black letters and a violet dot, for -300 colour fields and light paper.

- The same geometry ships as SVG files in assets/Logos.
- Never retype it in a font, recolour the letters, move the dot, or add a second dot.
