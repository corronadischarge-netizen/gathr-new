# FriendsGoing

A stack of friends' display pictures and a count of friends going, in ink. Friends are a fact, not a colour.

**Provide:** `people` as a list of `{ name, image }` (up to 3 are shown) and an optional `total`. `names` (plain strings) still works and shows initials.

- Friends with a display picture show it. Friends without one get their initials on a neutral disc. A stack can mix both.
- The copy is "Riya is going" for one friend and "4 friends going" for more.
- v14: the text is weight 500 (it was 600), so the faces lead.
