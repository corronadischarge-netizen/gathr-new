# Chip

Filter chips: filled dark pills that turn violet when selected.

**Provide:** `children` (1–2 words), `selected`, `onClick` and an optional `icon`.

- A filter row scrolls sideways and bleeds off the right edge, with chips `space-2` apart.
- Use words people say: "Open now", "Techno", "Rooftop", "No cover", "Date night".
- In the app, chips never get category colours. Colour belongs to status.
