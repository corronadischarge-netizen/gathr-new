# EventRow

A listing row with a rounded thumbnail, title, meta and a status badge or chevron button.

**Provide:** `title`, `day`, `time`, `venue`, `price`, `status` (`soldout`, `filling` or `onlist`), `image` (always a real photo) and `hue`.

- `filling` is a neutral grey badge: it's information, not a live moment, so it never borrows the yellow `now`. `soldout` is red `limit`, `onlist` green `go`.
