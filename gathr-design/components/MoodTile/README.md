# MoodTile

A dark tile with a 3D object breaking out of the top, for picking a vibe or category.

**Provide:** `title` (one or two words, sentence case), `kicker` ("I'm feeling"), `sticker` (an object url), `action` (a count, "6 nights"), `selected`.

- Tiles are `night-900` with a thin line; the object brings the colour. Selected turns violet.
- Scroll them in a row, the next tile peeking in. Never colour a tile by its category.
