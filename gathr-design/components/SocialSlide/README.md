# SocialSlide

A carousel slide (1080 × 1350, or 1920 tall for stories) in the same language as the rest of the system.

**Provide:** `pillar`, `kind` (`cover`, `body` or `end`), `headline`, `kicker`, `body`, `index` and `total`, `occasion`, `format` and `handle`.

**Rules:**
- **No italics.** The kicker is sentence case, DM Sans 500, in the pillar's hue.
- **Hierarchy:** headline (lowercase with the yellow full stop), then the kicker, then supporting text, then the small labels. Keep a clear jump between each.
- **Contrast:**
  - Cover: white on black.
  - Body: a dark plum numeral and dark text on the pillar colour.
  - End: white on violet.
- **No 3D objects.** Type, colour and the pillar tag carry the slide.
- Pass `headline` lowercase with no full stop; the component adds it.
- **Occasion covers** (`occasion`) add a still pillar bloom: Upgrade comedown, Insider sundowner, Mirror uv, Standard peak.
