# PhotoStack

A story-style photo with friends' shots tilted behind: for recaps, plans and social.

**Provide:** `images` (3 urls: centre, left, right), `reply` placeholder, `liked` and `onLike` (the heart is a real 44px button labelled Like / Unlike), and children as floating decorations: give each `className="g-float"` and a position (`ReactionBubble`, `TagPill`, `RingAvatar`, `Sticker`).

- Three decorations at most. Keep them off faces.
