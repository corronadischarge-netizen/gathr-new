# FactList

The title is `headline` (15/20 600). Labelled rows, each with an icon circle, a 13px label and a 16px value aligned to the right edge.

**Provide:** `rows` ([{icon, label, value, strong}]; `strong` sets a price at Jakarta 700, 20px), `title`, `note`, or `bare` for rows without the card.

- Use it for venue facts in `VenueHero` (bare) and for "The room" below the fold: Vibe, Music, Dress code, Entry.
- **Vibe** describes how the place feels. How full it gets belongs to the CrowdMeter, never here.
- Lucide icons only, in ink on a night-800 circle.
