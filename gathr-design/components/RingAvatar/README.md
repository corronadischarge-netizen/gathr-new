# RingAvatar

An avatar with a shiny ring that means something.

**Provide:** `image` or `name` (initials fallback), `sticker` (vibe sticker), `size`, `ring` (`brand` = something new, like a recap or plan; `go` = going; `none`), `badge` (`check`).

- Use in plans, friends lists and on photo stacks. One ring colour per row.
