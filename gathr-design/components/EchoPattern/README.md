# EchoPattern

gathr's brand pattern. The vibe-tag speech bubble, the shape of a conversation, echoes outward from the wordmark, each echo with its own tail. Each echo has a sharp outer edge, and its inner edge glows in a Bloom recipe, then fades into a deep ground of the same family. It replaces the old pill pattern.

**Provide:**
- `recipe`: `peak` (default), `uv`, `sundowner` or `comedown`.
- `rings`: the number of echoes, 3 to 5 (default 4).
- `logo`: set it to `false` for a plain backdrop with text on top, which you pass as `children`.
- `style`: give the frame its size. The pattern stays centred and crops to fill any shape.

**Use for:** end slides, share cards, merch, event backdrops, splash and loading screens.

**Rules:**
- It's a brand moment, like a Bloom, so keep it off everyday app screens.
- One pattern per frame. Don't put the pattern behind photos or long text.
- The wordmark stays white with the yellow full stop, centred in the innermost bubble.
- Shapes are bubbles, never circles, and there are no dots.
