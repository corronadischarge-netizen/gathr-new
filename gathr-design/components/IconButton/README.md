# IconButton

A round 48px icon button, like the search and heart buttons in the music-app reference.

**Provide:** `icon`, `label` (required, for screen readers), `variant`, optional `size` and `active` (the saved state).

| variant | use |
|---|---|
| `glass` (default) | top bar and over aurora |
| `solid` | on plain bg inside lists |
| `scrim` | over photos (save on a venue photo) |
| `tonal` | on colour cards |
