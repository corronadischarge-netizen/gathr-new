# Logos

The gathr wordmark (option J76): Plus Jakarta Sans Bold outlines tracked −6%, plus one true circle after the r. See the Logo section of the brand book for the construction.

- `gathr-wordmark-light.svg`: letters night-50 (#f7f5f0), dot yellow-300. For dark grounds, blooms and photos.
- `gathr-wordmark-dark.svg`: letters night-950 (#0a0a0a), dot violet-500. For light paper and -300 colour fields.
- `gathr-wordmark-mono-white.svg`: all white. For one-ink merch, embossing and knock-outs.
