# Stickers

gathr's 3D objects and sticker pack: glossy renders on transparent backgrounds, 256 × 256 PNG.

- **Objects** (no text: disco-ball, headphones, cocktail, champagne, vinyl, ticket, wristband, camera, sunglasses, mic, speaker, shaker, lighter, phone, lanyard-pass, spotlight): use in the app via `Sticker`, `MoodTile` and `MapPin`.
- **Sticker pack** (everything else: slogans, smileys, labels): social, posters, merch and the onboarding collage only.
- Never recolour, outline or crop them. Show them on dark grounds. Don't feature lighters, cash or bottles as a night's main image.
